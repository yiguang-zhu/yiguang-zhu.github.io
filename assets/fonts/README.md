# Website typefaces

Latin text uses Adobe Source Serif 4 (body and headings) and Source Sans 3 (navigation and metadata). Chinese characters continue to use the existing Songti SC / Noto Serif CJK SC / SimSun serif stack. A Latin-first font stack prevents English in Chinese articles from falling into a CJK font's Latin glyphs.

The WOFF2 files are self-hosted, unmodified upstream files. Licenses are included alongside them.

- Source Serif: https://github.com/adobe-fonts/source-serif/tree/80d3f8894c09c937bebfa9011247d2e1c79fd6f4/WOFF2/TTF
- Source Sans: https://github.com/adobe-fonts/source-sans/tree/87b37a2daaed80fcb8e8ccb0085c4d72ddade12e/WOFF2/TTF
